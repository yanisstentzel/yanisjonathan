# Run 4 Smiles 2027

Site vitrine d'un projet de groupe (événement caritatif **fictif**) : une course solidaire suivie d'un concert, le samedi 12 juin 2027, dans 4 capitales — Paris, Riga, Kyiv et Séoul — pour récolter des fonds au profit des enfants sans-abri.

## Structure

```
index.html        page unique (sections : accueil, projet, villes, programme, billets, dons, FAQ)
css/style.css     styles (couleurs du logo dans :root)
js/main.js        menu mobile, compte à rebours, barre de dons, animations
assets/img/       logos (complet, recadré, pictogramme)
```

## Lancer en local

Ouvrir `index.html` dans le navigateur, ou :

```
python3 -m http.server 8000
```
